# Automate Testing

**Rule:** Sempre que houver uma modificação no código-fonte, ou após finalizar uma tarefa, você DEVE rodar os testes da aplicação para garantir que nada foi quebrado.

1. Acesse o diretório `backend` (se a mudança for no backend).
2. Execute `npm test`.
3. Verifique os resultados e corrija eventuais erros antes de dar a tarefa como concluída.
